# DB_Project
Lost and Found System
This project is a database-based system where users can report lost or found items. The system stores data and helps in matching items.

- Database schema


### v1.1
Some changes were made in the database structure and ERD design.Added expiry handling policy for found items like expiry date, admin action  and admin note fields. We also added expiry_days in categories table and updated item status by adding expired state.
